## Purpose

Reference repository for PlantUML diagram syntax — UML and non-UML formats. Contains test files, examples, and utilities for exploring PlantUML capabilities including YAML/JSON data rendering, ArchiMate, EBNF, SALT wireframes, WBS, and standard UML diagrams.

## Directory Layout

| Directory | Contents |
|-----------|----------|
| `UML/` | Standard UML diagram examples (class, sequence, state, etc.) |
| `supported_nonUML/` | Non-UML format tests (YAML, JSON, ArchiMate, EBNF, SALT, WBS) |
| `src/utils/` | Python utilities (tree structure generator) |
| `docs/` | Project documentation |
| `tools/` | Tool scripts |
